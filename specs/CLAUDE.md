# Specifications (`specs/`) Guidelines

## Spec-Is-Truth Principle
- Specifications in this directory define the exact behavior and rules of the system.
- Any change to code MUST be preceded or accompanied by a corresponding spec update.
- Each specification file MUST contain an explicit **Acceptance Criteria** section with testable Given-When-Then criteria and unique `AC-NN` identifiers.
- Synthetic dummy data ONLY.
